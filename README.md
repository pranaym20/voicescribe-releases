# VoiceScribe for macOS

Download the latest DMG from [Releases](https://github.com/pranaym20/voicescribe-releases/releases/latest), open it, and drag VoiceScribe to Applications.

Once installed, VoiceScribe updates itself (menu bar → Check for Updates…).

`appcast.xml` is the Sparkle update feed. Source code is not in this repository.
